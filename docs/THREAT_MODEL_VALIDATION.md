## 2. Summary of Residual Risk Analysis

1. **Physical Endpoint Vulnerability**: If an adversary acquires root/administrator privileges on a recipient's physical workstation *while an authorized user has decrypted the keystore in RAM*, the plaintext document and ephemeral key material could theoretically be read from kernel space. TraceCrypt mitigates this through prompt GC, ephemeral variable lifecycles, and Argon2id encryption at rest, but cannot guarantee protection against an attacker with full hardware control.
2. **Physical Photographing / Optical Bleed**: TraceCrypt embeds imperceptible DWT-DCT watermarks that survive re-encoding, screen capture, downsampling, and printing/scanning. However, extreme physical destruction that obliterates more than 75% of image content drops the correlation below detection threshold, leading gracefully to `UNVERIFIABLE` rather than false attribution.
3. **Byzantine Fault Tolerance Bound**: The 4-validator network preserves complete Byzantine fault tolerance up to $f = 1$ compromised node ($N = 4 \implies 3f + 1$). If 2 or more validators are compromised simultaneously ($f \ge 2$), consensus safety can no longer be mathematically guaranteed.
